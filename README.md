# DIC4：overleaf draft for conference using MCP and openspec

## 1. 專案簡介

本專案透過 MCP（Model Context Protocol）、OpenSpec、GitHub 與 Overleaf，建立 AI 輔助學術論文撰寫流程，並依照 IEEE Conference 格式完成論文初稿。

本次論文主題為 **Food Guardian**，透過 AI Agent、RAG、食材庫存管理、食譜推薦及食品安全判斷，協助使用者管理家庭食材並減少食物浪費。

## 2. 作業要求
- 使用 Overleaf 完成 IEEE Conference 論文初稿。
- 將 OpenSpec 相關規格與文件上傳至 GitHub。

## 3. 論文撰寫與修改

本次論文以 ICEIB Conference 為目標，使用 Overleaf 進行 LaTeX 論文撰寫，並遵循 IEEE 雙欄排版格式。

**本次提交的論文並非直接使用 AI 生成的初稿，而是經過後續檢查、修改與排版調整的版本。**

主要修改內容如下：

- 調整論文章節架構與內容。
- 修正 IEEE 雙欄排版問題。
- 調整超出頁面範圍的表格。
- 修正過長公式造成的欄位溢出問題。
- 改善論文整體的可讀性與呈現方式。

## 4. OpenSpec 規格管理

使用 OpenSpec 建立規格驅動的論文撰寫流程，主要用途包含：

- 定義論文撰寫目標與需求。
- 規劃論文章節及內容架構。
- 建立 IEEE 論文格式規範。
- 管理論文撰寫與修改任務。
- 維持論文內容與研究方向的一致性。

相關規格與文件存放於 `openspec/` 資料夾中。

## 7. 作業總結

本次作業結合 AI 輔助論文撰寫、OpenSpec 規格管理及 GitHub 版本控制，並透過 Overleaf 完成 IEEE 會議論文初稿。初稿完成後，進一步進行內容檢查與排版修正，以提升論文的完整性、可讀性及格式正確性。
